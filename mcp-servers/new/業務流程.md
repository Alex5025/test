# 透過 AI 產生模板

1. 使用者傳入自然語言
2. 從 tags table 中撈出所有 tag_list (List<String> tags)
3. 將使用者傳入的自然語言和 tag_list 一起送給 LLM 並請 LLM 依據 自然語言, 在 tag_list 中 挑選出 10 個與使用者傳入的自然語言最接近的 tags
4. 將 AI 推薦的 tags 與 templeats 資料庫中得資料比對, 並計算 ai 推薦的 tags 與各筆 template_id 下的各組 tags 匹配度 ,例如當 ai 回覆的 10 個 tags 在列表-進階 的 json_data 中有 7 個相同 可靠度視為 70%
```javaScript
{
        template_id: "列表-進階",
        json_data_function: ["搜尋", "查詢", "篩選", "狀態", "重置", "展開", "勾選", "多選", "批次處理", "多項操作", "操作", "匯出", "新增", "備註", "移動", "查看", "狀態篩選", "草稿", "排序"],
        json_data_situation: ["情境", "案件", "進度", "管理", "交易", "紀錄", "流程", "追蹤", "審查", "審核", "監控", "報表"],
        json_data_business: ["業務", "銀行", "金融", "經辦", "信貸", "客服", "風險控管", "合規", "稽核", "交易", "授信", "審核", "客戶", "申訴", "營運", "投信", "人事", "財務", "理財", "外匯", "內控", "帳務", "人員"],
        json_data_layout: ["佈局", "資料列表", "表格", "篩選區", "欄位設定", "分頁", "清單"],
        update_id: "system",
        update_timestamp: new Date()
    }
```
