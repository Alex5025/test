## 🛠️ 新增工具

### `evaluate_confidence`
**功能**：評估輸入內容的可信度，支援標籤或自然語言輸入

**參數**：
- `input` (必填)：輸入內容，可以是逗號分隔的標籤或自然語言描述
- `input_type` (可選)：輸入類型，支援 "tags"、"natural_language"、"auto"（預設）

**範例使用**：
```javascript
// 自然語言輸入
{
  "input": "我需要一個信用卡申請表單",
  "input_type": "auto"
}

// 標籤輸入
{
  "input": "申請,表單,輸入",
  "input_type": "tags"
}
```

## 📈 可信度評估指標

### 1. **標籤覆蓋率** (25% 權重)
- 計算提取標籤中有多少是系統已知標籤
- 100% = 所有標籤都在系統中

### 2. **模板匹配度** (35% 權重)
- 基於最佳匹配模板的匹配程度
- 考慮匹配標籤數量和總輸入標籤數量

### 3. **輸入品質** (25% 權重)
- **標籤輸入**：評估標籤數量和有效性
- **自然語言輸入**：評估描述完整性和專業詞彙使用

### 4. **語義一致性** (15% 權重)
- 分析標籤間的相關性和模板匹配的一致性
- 考慮多個模板間的競爭關係

## 🎯 可信度等級

| 分數範圍 | 等級 | 建議 |
|----------|------|------|
| 80-100% | 極高可信度 | 可以安心使用推薦結果 |
| 65-79% | 高可信度 | 推薦結果可靠，建議確認 |
| 45-64% | 中等可信度 | 需要進一步優化輸入 |
| 25-44% | 低可信度 | 建議重新描述需求 |
| 0-24% | 極低可信度 | 輸入不夠明確，需重新整理 |
